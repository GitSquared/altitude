Notes:(unless otherwise specified)
  1. Do not scale this drawing. Read the codes; the tables carry the values.
  2. Units are terminal cells: columns horizontal, rows vertical. One cell is drawn 1 col : 2 row, so the sheets read like a terminal.
  3. Reference terminal W = 160 col, H = 48 row. Values the source computes are shown as formulas of W, H and the content box.
  4. Regions are slots, not copy. HUG = sized by content, FLEX = takes what is left, FILL = parent width.
  5. Grayscale is a translation, not a palette: focus = hatched fill, heading = 1.6 px, primary = 1 px, muted = 0.8 px dashed slot.
  6. Anything the source does not state is [TBD] and drawn proportional.
